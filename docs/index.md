# SynBioKit Tutorial

Welcome to the hands-on SynBioKit tutorial.

SynBioKit is a browser-based platform for exploring,
visualising, validating and converting synthetic biology
designs represented using SBOL.


By the end of this tutorial, you will be able to:

- Load an SBOL design into SynBioKit
- Explore its entities and relationships
- Visualise the design using different views
- Validate SBOL documents
- Identify validation errors
- Convert designs between SBOL formats
- Explore graphical representations of biological designs
