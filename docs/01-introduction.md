# Introduction

## What is SynBioKit?

SynBioKit is a web-based platform for working with
synthetic biology designs represented using SBOL.

It provides integrated tools for:

- Visualisation
- Validation
- Format conversion
- Design exploration

## Why SynBioKit?

Synthetic biology designs can contain many interconnected
entities and relationships.

Although SBOL provides a standard representation for these
designs, understanding and analysing complex SBOL documents
can be challenging.

SynBioKit provides interactive and graphical interfaces that
allow users to explore these designs directly in a web browser.

## Tutorial Workflow

During this tutorial, we will follow a biological design through
a typical SynBioKit workflow:

**Load → Explore → Visualise → Validate → Convert → Export**
