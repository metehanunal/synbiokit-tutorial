# Getting Started

In this section, we will prepare everything needed for the hands-on activities in this tutorial.

## Requirements

To follow this tutorial, you will need:

- A modern web browser such as Chrome, Firefox, Edge, or Safari
- Internet access
- The example SBOL files provided in this repository

## Open SynBioKit

Open SynBioKit in your web browser using the link below:

[Open SynBioKit](https://synbiokit.keele.ac.uk/)


## Tutorial Files

The example SBOL documents used throughout the tutorial are available in the `examples` directory of this repository.

[Open the example files](../examples/)

You will use different example files to explore the main features of SynBioKit, including:

- Network view
- Hierarchical view
- Design validation
- Format conversion


## Tutorial Workflow

During the tutorial, we will follow a typical SynBioKit workflow:

**Load → Explore → Visualise → Validate → Convert**

Each section contains:

1. A short explanation of the feature
2. Step-by-step instructions
3. A hands-on activity
4. An expected result
